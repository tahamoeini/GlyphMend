# Research and design material

The current product and operations source of truth is in [docs/](../docs/README.md); current release readiness is in [docs/roadmap.md](../docs/roadmap.md). Files in this directory preserve research, concept work, and implementation prompts. They are not an active backlog or product contract unless a current guide explicitly links them for a specific purpose.

## Material in this directory

- GlyphMend_Extraction_Reconstruction_Master_Plan.md and GlyphMend_AI_Coding_Agent_Master_Prompts.md preserve the original extraction planning and prompt set. Their post-PR assumptions and future work may be superseded by the implementation.
- stitch_glyphmend_desktop_interface_design/ contains visual concepts and design tokens. Treat its HTML and images as design references, not evidence that the shipped interface matches them.
- archive/ contains earlier upgrade research and agent plans. Version-sensitive statements and external citations in those snapshots should be checked against current primary sources before reuse.

For implemented behavior, use the code and current guides rather than inferring status from research documents.
